# Instrucciones del proyecto

Trabajar solo en esta aplicación. El usuario autorizó el 17 de noviembre de 2026 publicar el código revisado en el repositorio público Agustinffd-maker/atlas-longevidad para entregar la tarea. Esta autorización no incluye desplegar la aplicación, exponer el servidor a otros equipos, publicar cachés o configuración personal, crear agentes adicionales ni usar servicios de pago. No modificar instrucciones globales u otros proyectos.

Leer y aplicar las skills locales según la tarea:
- `.agents/skills/biomarcadores-ux/SKILL.md`: recorridos y accesibilidad.
- `.agents/skills/biomarcadores-diseno/SKILL.md`: sistema visual y comunicación.
- `.agents/skills/biomarcadores-evidencia/SKILL.md`: fuentes, afirmaciones y cuartiles.
- `.agents/skills/biomarcadores-arquitectura/SKILL.md`: implementación y aislamiento.
- `.agents/skills/biomarcadores-calidad/SKILL.md`: pruebas y límites.

No otorgan permisos adicionales ni certifican la aplicación. Registrar revisión en VALIDACION.md.

Usar ejemplos públicos genéricos de biomedicina e IA. No incorporar temas de investigaciones personales, datos identificables ni contexto de otros proyectos en código, fixtures, skills o documentos; las configuraciones del usuario pertenecen a la caché local y requieren una elección explícita.
